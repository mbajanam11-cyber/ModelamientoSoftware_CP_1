# Caso de estudio: Sistema de gestión de almacén de inventario
Logistock es un sistema concebido para optimizar la administración y el seguimiento de inventarios, brindando soporte en la recolección, alistamiento y verificación de productos. La plataforma estructura sus accesos según la responsabilidad del usuario: el Preparador efectúa la extracción y armado de los pedidos, mientras que el Supervisor coordina las operaciones diarias y valida las modificaciones sobre el stock.
Los modelos del caso de estudio alojados en el repositorio comprenden:
* Diagrama de casos de uso: Define los actores, sus permisos dentro del sistema y cómo se relacionan con las funciones principales.
* Diagrama de secuencia: Muestra la cronología de las interacciones entre los usuarios y el software a lo largo de un procedimiento.
* Diagrama de comunicación: Detalla los objetos o componentes clave que intervienen en la tarea y el flujo de mensajes entre ellos.

La estructura interna del repositorio incluye un fichero README explicativo junto con carpetas dedicadas a cada Trabajo Práctico Experimental, las cuales almacenan sus esquemas respectivos.
